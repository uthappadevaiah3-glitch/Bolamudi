00 / STRATEGYPositioning & Design Principles

Every token and component in this document exists to answer one commercial question: would a 45-year-old project director at an IPP forward this website to their investment committee? Not "does it look nice."

The strategic problem

Bolamudi Enterprise sells de-risking. A developer with ₹800 crore of capex committed does not buy land aggregation or liaison — they buy the elimination of the two failure modes that kill utility-scale projects in Karnataka: land title disputes and approval timelines. The website's job is to make a buyer believe those failure modes are survivable with this firm.

The credibility gap is structural. Bolamudi is a small firm competing for attention against balance sheets. The founder's 20 years is the entire asset. So the site must trade on specificity, not scale — districts named, approvals enumerated, sequences documented, timelines quantified. Vagueness reads as inexperience. Detail reads as experience.

Six principles

PrincipleWhat it means in the interface
1. Evidence over adjectiveNever write "extensive experience." Write "1,240 acres aggregated across 6 districts." Every claim on the site must resolve to a number, a district name, or a named statutory instrument. The design system therefore over-invests in Statistics, Tables and Timeline components and under-invests in decorative hero art.
2. Institutional restraintSharp corners, hairline borders, near-zero shadow, one accent colour used sparingly. Gradients, glassmorphism, glow effects, pill buttons, emoji and 3D illustration are banned — they are the visual grammar of SaaS startups, which is the exact category the client asked not to resemble.
3. Density is trustConsultancy buyers read. Whitespace-heavy, one-sentence-per-screen layouts signal that the firm has nothing to say. Body copy runs 60–75 characters, sections carry real paragraphs, tables are dense. Apple-style airiness is used only in the hero and section transitions, not in content.
4. Typographic hierarchy carries the designWith no photography budget guaranteed and a logo that cannot scale (see §01), the type system does the heavy lifting. This is the Stripe model: a rigorous scale, two families, obsessive optical alignment.
5. Motion confirms, never entertainsAnimation exists to confirm state change and orient the eye on scroll. Duration ceiling 520ms. No parallax, no scroll-jacking, no counter animations longer than 1.2s. Siemens Energy's model.
6. Accessible by constructionWCAG 2.2 AA is a floor, not a retrofit. Every token pair in this document has a computed contrast ratio published beside it. Investment firms and infrastructure majors increasingly run accessibility checks in vendor onboarding — failing one is a commercial risk, not a moral one.
Design decision — why not a "green energy" visual language? The obvious move is leaf motifs, bright solar-orange CTAs and turbine photography. Rejected. Every competitor in this space uses it, so it differentiates nothing; more importantly it reads as marketing, and Bolamudi's buyer is deeply suspicious of marketing. The logo already supplies the green. The interface stays sober so the logo's warmth reads as heritage rather than eco-branding.

01 / BRAND INPUTLogo Assessment & Constraints

You supplied Option 2. The palette below is extracted faithfully from it. But you asked for honesty, so: the mark has three properties that will actively fight the positioning you described, and the design system has to be built to compensate.

Problem 1 — the script wordmark contradicts the category. "Bolamudi" is set in a formal calligraphic script with a swash. That letterform family belongs to hospitality, jewellery, catering, event management and wedding services. Not one of Black & Veatch, AECOM, Arup, WSP, Jacobs, Siemens Energy or ReNew uses a script logotype — all seven use a grotesque or neo-grotesque sans. A procurement manager scanning a shortlist will subconsciously bucket a script wordmark as "small local business." This is the single largest credibility leak in the brand.

Problem 2 — the mark does not survive at 32px. The B-monogram contains a building silhouette, a solar-panel-like grid, a swoosh arc and five layered field furrows. At header height (32–40px) those elements collapse into a dark green blob. There is no simplified mark, no favicon-safe variant, no monochrome variant.

Problem 3 — the lockup is a poster, not a logo. The four-word tagline strip and the five icon columns beneath it are a brochure slide. They cannot be used in a header, a footer, an email signature or a favicon. In practice you have no usable logo asset yet — only artwork.

Problem 4 — the gold gradient will not render. The gold is a metallic gradient. Metallic gradients degrade badly at small sizes, in single-colour print, on dark backgrounds, and in email clients. It must be flattened to one solid gold before it can be a web asset.

Recommendation

What this design system does about it. Until the wordmark is re-cut, the system deliberately restrains the logo: it appears at fixed small size in the header and footer only, is never enlarged in the hero, and is never set over photography. The type system (§03) is what establishes engineering authority on every page. If the wordmark is re-cut, nothing else in this document changes — the colour ramps are extracted from the mark's hues, not its letterforms.

Why not a pure grey? Pure neutral greys (#808080 family) placed beside a saturated forest green read as dirty — the eye perceives a magenta cast by simultaneous contrast. Colour usage ratio

Approximate area of any given viewport: 72% neutral surfaces · 18% forest · 7% imagery · 3% gold. Gold above ~5% of a viewport starts to read as decorative and the page loses its institutional register. Gold is permitted on: eyebrow labels, section numerals, the 2px rule under section headings, statistic key figures, timeline nodes, and hover underlines. It is not permitted on: primary buttons, large fills, body text on light, or icons at small sizes.

03 / FOUNDATIONSTypography

Three families with strictly separated jobs. Because the wordmark cannot carry authority (§01), the type system must.

FamilyRoleRationale
ArchivoDisplay / headings / UI labelsA grotesque drawn from American gothic signage — slightly condensed, high x-height, low contrast, flat terminals. It reads engineered rather than friendly, which is exactly the correction the script wordmark needs. Variable, open-licence, excellent at 700 weight for large display sizes. Direct free equivalent to the Söhne/GT America register used by top-tier engineering firms.
InterBody / long-form / formsDesigned for screen UI at small sizes; the largest x-height-to-cap ratio in its class, disambiguated Il1, and — critically — real tabular numerals. Bolamudi's pages are full of MW figures, survey numbers and acre counts. Neutral enough not to compete with Archivo.
IBM Plex MonoTechnical dataReserved for capacity figures, survey numbers, coordinates, dates, reference codes and section numerals. Monospace here is a credibility signal — it says "this number came from a document." Used sparingly, it does more for perceived rigour than any illustration.
Why not a serif? A serif (the Arup / legal-consultancy register) was considered and rejected. Serifs pair badly with an already-ornate script wordmark — the page would read as two competing calligraphic voices. A grotesque creates deliberate contrast: the logo is heritage, the interface is engineering. If the wordmark is re-cut as recommended, a serif becomes viable for pull-quotes only.

Licensed upgrade path: if budget allows, Archivo → Söhne or GT America; Inter → Söhne or Suisse Int'l; Plex Mono → Söhne Mono. The scale below is unchanged by the substitution.

Typographic rules

Measure45–75 characters. Enforce with max-width:70ch on all body containers. Full-bleed 1200px paragraphs are the most common failure on consultancy sites.
Optical trackingNegative tracking scales with size: −0.028em at 64px down to 0 at 16px, then positive +0.01em below 13px. Uniform tracking across a scale is the tell of an amateur type system.
Numeralsfont-variant-numeric:tabular-nums is mandatory in tables, statistics, timelines and any animated counter — proportional numerals make counters visibly jitter.
Weights in useArchivo 600 / 700 only. Inter 400 / 500 / 600 only. Plex Mono 400 / 500. Nine total files. Never use 300 or lighter — thin weights fail contrast perception at 14px and read as fashion, not engineering.
CaseUppercase only for eyebrows, table headers and badges, always with ≥0.07em tracking. Never uppercase a full heading — it destroys word-shape recognition and slows reading ~12%.
Widows & orphansNon-breaking space before the last word of every H1/H2. A single-word second line in a display heading is the most visible polish failure on a landing page.
Loadingfont-display:swap with metric-matched fallbacks (Arial for Inter/Archivo) to keep CLS < 0.02. Self-host via next/font — no third-party font request on a site targeting institutional buyers behind corporate proxies.

Vertical rhythm law

Proximity encodes hierarchy. The space above a heading must always be larger than the space below it — otherwise the heading visually belongs to the paragraph it follows rather than the one it introduces. Enforced ratios: H2 → 96px above / 24px below. H3 → 48px above / 12px below. H4 → 32px above / 8px below. This single rule fixes more perceived-quality problems than any other.

05 / FOUNDATIONSRadius, Border & Elevation

This is where consultancy sites are won or lost. Rounded corners and soft shadows are the visual signature of consumer SaaS. Bolamudi's system is border-first: structure is drawn with hairlines, not with shadow.

Radius

2pxBadges, tags, table cell highlights, skeleton bars

8pxMaximum. Large media containers and the hero visual only.
fullAvatars and the theme switch only. Never buttons — pill buttons are the single strongest startup signal in an interface.
Why 3px on buttons and not 8px. At 8px+ radius the eye reads "app." At 0px it reads "brutalist/dev tool." 3px is the register of Bloomberg, Stripe's dashboard, Siemens and every serious engineering interface — the corner is softened enough to feel manufactured, not enough to feel playful. Consistency matters more than the exact value; what kills a design system is having 4px, 6px, 8px and 12px buttons on the same page.

Shadows in dark theme do not work. A black shadow on a near-black canvas is invisible. In dark mode elevation is communicated by surface lightening — canvas #0C100E → subtle #161B18 → muted #1E2521 → overlay #262E2A — with shadow retained only for spatial separation of true overlays. Both mechanisms are already in the token set; components need no conditional logic.
Border hierarchy. --border-subtle for decoration (cards, dividers) — no contrast requirement. --border-control for anything a user can interact with (inputs, checkboxes, radio, unfilled buttons) — must be ≥3:1 under WCAG 2.2 SC 1.4.11. Using the subtle border on inputs is the most common accessibility failure in Tailwind-based builds, because border-gray-200 is 1.3:1.

PatternSpecification
Section revealopacity 0→1, translateY 16px→0, 520ms ease-out. Trigger at 20% viewport intersection. Fires once — re-animating on scroll-back is nauseating and signals gimmickry.
Stagger60ms between siblings, capped at 6 items (360ms total). Beyond 6, animate the container as one unit — a 12-card grid staggering at 60ms takes 720ms and the last card looks broken.
Counter (statistics)Ease-out over 1200ms max, tabular numerals, starts at 60% of final value not zero. Runs once on first intersection.
Card hovertranslateY(-2px) + border-subtle→border-brand + shadow flat→xs, 160ms. No scale transform — scaling resamples text and looks cheap.
AccordionHeight auto-transition 220ms + chevron rotate 180° 220ms. Content fades in at 160ms with 60ms delay so text does not appear to squeeze.
Page transition140ms cross-fade only. No slide, no wipe. Route changes on a content site must feel instant.
Sticky headerOn scroll >80px: height 88px→64px, shadow none→sm, background transparent→canvas, 220ms.
Banned outright: parallax backgrounds · scroll-jacking / pinned sections · horizontal auto-carousels · text scramble/typewriter effects · bounce or elastic easing · looping background video · cursor followers · any animation exceeding 520ms except the statistics counter.
Reduced motion is not optional. Under prefers-reduced-motion: reduce all transforms are removed and durations collapse to a 100ms opacity fade. Content must never be hidden pending an animation that will not run — implement reveals as opacity from 1 with JS adding the animation class, so a user with JS disabled or motion reduced sees fully rendered content. Vestibular disorders affect roughly 1 in 20 adults; this is also a WCAG 2.3.3 requirement.

Why gold is never a primary button. Gold-500 on white is 2.62:1 — text on it fails, and a gold fill with dark text sits at 6.99:1 but visually screams "sale banner." Gold's job in this system is to mark (rules, numerals, eyebrows), not to act. Forest carries every action.
Button copy rules. Verb + object, sentence case, never more than four words. "Request a consultation" not "Submit." "Download the capability statement" not "Click here." Never "Learn more" — it tests worst of any CTA label because it promises nothing.

RuleSpecification & rationale
Label positionAlways above the field, 13px Archivo 600, 6px gap. Floating labels and placeholder-as-label are banned: they fail for screen readers, disappear on input, break autofill styling, and cause measurable error-rate increases in usability testing.
Required markingRed asterisk with aria-hidden plus the native required attribute. If most fields are required, mark the optional ones instead — a form of eight asterisks reads as hostile.
Border contrast--border-control at 3.62:1 light / 4.28:1 dark. Tailwind's default border-gray-200 is 1.32:1 and is a WCAG 1.4.11 failure — this is the most common bug in shadcn/ui builds.
FocusBorder → forest-700 plus a 3px forest-50 halo. The halo does the visual work; the border change does the semantic work for high-contrast mode users.
ErrorBorder danger-600, message below the field with a warning glyph, linked via aria-describedby, and aria-invalid="true". Colour is never the only signal (WCAG 1.4.1). Errors are specific and instructive — "Enter a complete work email address, e.g. name@company.com" not "Invalid input."
Validation timingValidate on blur, not on keystroke. Re-validate on keystroke only after the field has already errored once. Validating while typing marks every field invalid before the user finishes and is the single most irritating form pattern.

PhoneFixed +91 prefix, inputmode="numeric", accept spaces and hyphens, normalise server-side. Never reject a number for formatting.
Selection controls18px box with a 44px hit area extended via the label. Checkbox radius 2px, radio 50% — the shape difference must be visible at a glance because it signals single vs multiple choice.
Switchrole="switch" + aria-checked. Only for immediate-effect settings. A form field that requires Submit uses a checkbox, never a switch.
Touch targets44×44px minimum, 8px minimum spacing between adjacent targets.

The two failures this system is specifically engineered against. (1) Low-contrast borders — the shadcn/Tailwind default palette puts input borders at ~1.3:1, which fails SC 1.4.11 on every form. Hence the dedicated --border-control token. (2) Gold text — the brand's own accent colour fails contrast on white, and the natural instinct will be to use it for headings and links. Hence the explicit ban and the gold-700 substitute.

26 / GOVERNANCEImplementation & Governance

Token architecture

Three layers, strictly enforced. Primitives (--forest-800) → semantic (--bg-brand) → component (--btn-primary-bg, optional). Components must never reference a primitive directly. Any pull request that hard-codes a hex value or references a primitive from a component is rejected. This single rule is what makes the dark theme a 40-line change and what will make a future rebrand survivable.

Tailwind configExtend theme.colors with the semantic names only — do not expose primitives to utility classes, or developers will use bg-forest-800 and the theming layer dies. Map to CSS variables so dark mode is a class swap, not a variant explosion.
shadcn/uiAdopt Button, Input, Select, Checkbox, RadioGroup, Accordion, Dialog, Sheet, Tabs, Table, Badge, Form. Override the default border tokens immediately (see §25). Do not adopt its default radius scale — set --radius: 3px.
Framer MotionCentralise variants in one motion.ts module exporting fadeUp, stagger, drawRail, countUp. Every animation on the site imports from it. Ad-hoc inline animation values are how motion systems rot.
FontsSelf-host via next/font/google, subset to latin, preload the display face only. No runtime request to fonts.googleapis.com — corporate proxies block it and the site loses its typography for exactly the audience it is built for.
