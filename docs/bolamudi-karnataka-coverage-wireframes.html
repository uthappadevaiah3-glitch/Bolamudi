Karnataka Coverage — Layout & Interaction Wireframes

Structural diagrams only. No brand colours, no final typography. Tier colours are indicative to show hierarchy, not palette.

Diagram 01

Desktop full page — ≥1280px

Nine zones. The map module (Z3) sits third, not first: the visitor needs the orientation strip to know what question the map answers before it is worth interacting with.

Tier 1 · Core Operating Tier 2 · Active Coverage Tier 3 · Statewide Capability Tier 0 · Not claimed (non-interactive) Selected / attention

The Karnataka outline shown is a schematic placeholder for layout purposes only — the production map is generated at build time from a verified 31-district boundary file including Vijayanagara.

Diagram 02

Map module — scroll behaviour and column responsibilities

The single most important layout decision on the page: the map is sticky inside the module while the panel scrolls. Dossiers run to 700 words; if the map scrolled away, the visitor loses the spatial context that makes the text mean anything, and has to scroll back up to change district.

Diagram 03

District interaction state machine

Hover must be pure CSS. A React state update per mousemove across 31 paths is the most likely performance bug in this build and will make the map feel sticky. React owns selection only.

Diagram 04

Mobile — <768px · list-first, map-second

At 375px wide, Yadgir gets a tap target of roughly 18×22px against a 44px minimum. The desktop map does not survive the transition, so it is demoted to a non-interactive orientation graphic and the district list becomes the primary instrument.

Left: mobile coverage section. Right: full-screen district sheet. Tablet (768–1279px) stacks map above panel at full width — the three-column desktop layout is never attempted below 1280px, because the panel drops under 380px and the dossier becomes unreadable.

Diagram 05

Coverage tiering — the honesty architecture

The grey districts sell the coloured ones. A map that lights up Udupi as brightly as Koppal tells an informed visitor you don't know Karnataka. A map that greys it out with an honest reason tells them you do.

Diagram 06

SEO cluster and scalability path

Spoke pages are generated only for districts that carry a genuine dossier. Thirty-one thin auto-generated pages is textbook doorway-page behaviour and puts the whole domain at risk.

Phase 4 is the moment this becomes a genuine track-record map — the page you originally wanted. The schema carries a nullable engagements[] field from day one so the transition is additive.
