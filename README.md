# Bolamudi

Website for Bolamudi Enterprise (bolamudi.com).

| Folder | What's in it |
|---|---|
| `site/` | The website source. Build with `python site/build.py`; see `site/README.md` for where to change what. |
| `docs/` | Planning and design: strategy, information architecture, page specs, wireframes, SEO, brand guidelines. |
| `docs/brand/` | Logo board for the logo in use (option 2), and the earlier logo concept kept for reference. |

`bolamudi-site.zip` is the built site, ready to upload. Every build recreates it.
